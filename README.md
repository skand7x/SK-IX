## ✨ Features

* 🚀 **Blazingly Fast:** Near-zero background processes to keep resource usage minimal.
* 🎨 **Dynamic Auto-Theming:** Automatically extracts color palettes from your wallpaper on the fly.
* 🖥️ **Full DE Experience:** Window management, notifications, volume control, and app launcher—without the heavy DE bloat.
* ⚡ **Fluid Animations:** Smooth layout transitions powered by Hyprland.
